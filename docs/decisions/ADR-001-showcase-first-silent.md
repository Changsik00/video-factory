# ADR-001: 첫 제품은 무음 이펙트 쇼케이스(자막만)로 한다

## 📚 Context
초기 제안서는 주제가 있는 설명 영상(음성 포함)을 전제로 했다. 2026-10-27에 사용자가 "주제보다 이펙트와 샘플을 볼 수 있는 프로젝트, 목소리는 차후, 자막만"으로 방향을 바꿨다.
HyperFrames 레지스트리에는 완결된 샘플 장면(블록 210개)과 자막 컴포넌트(`caption-*`)가 있어 소재가 이미 있다. 음성이 없으면 TTS 선택, 한국어 음성 품질, 음성↔장면 동기, 단어 정렬이 모두 불필요하다.

## 🎯 Decision
첫 제품은 이펙트·샘플 쇼케이스이며 음성(TTS)을 쓰지 않고 자막만 넣는다. 시간은 사람이 정한 값(`script.md`의 duration, `captions.srt`)이다. 음성은 별도 phase에서 새 기획 후 다룬다.

## 📊 Consequences
- **긍정**: 의존 도구와 외부 서비스가 줄어든다. SRT가 입력으로서 의미를 가진다. 레지스트리 메타를 카탈로그 색인에 거의 그대로 쓸 수 있다.
- **부정**: 설명형 콘텐츠는 만들 수 없다. 음성·정렬 기능은 미검증 상태로 남는다. 템플릿 모음이라는 인상 때문에 YouTube 정책상 편집 기여(변형, 해설, 분류)가 필요할 수 있다 (2차 자료 기준, 공식 확인 필요).
- **중립**: 음악·효과음 사용 여부는 이 결정이 정하지 않는다. 사용자가 요청할 때 별도로 정한다.

## 🔀 Alternatives
- **주제 있는 설명 영상(음성 포함)**: 제안서 원안 — 비채택 이유: TTS·정렬·동기 비용이 크고, 도구 능력이 실측되기 전이라 가설이 많다.
- **음성 포함 쇼케이스**: 소재는 같고 음성만 추가 — 비채택 이유: 첫 제품의 검증 범위를 불필요하게 넓힌다.
