# ADR-005: 이 프로젝트는 개인 제작 도구로 시작한다

## 📚 Context
phase-01 회고에서 "개인 제작 도구인가, 다른 사람에게 서비스로 제공하는 판매 제품인가"가 미정으로 남아 있었고 (`docs/plan/multi-format-presentation-plan.md` §7 질문 1) Hypit 사용 가능 여부와 클라우드 렌더 사용 여부가 여기에 달려 있었다.
- Hypit `LICENSE`(2026-10-31 확인, 법률 검토 아님): 자기 조직의 업무(상업·고객 작업 포함)와 단일 테넌트 배포는 허용하고, 조직 밖 둘 이상의 당사자가 별도 워크스페이스를 갖는 멀티테넌트 서비스나 상업적 재배포는 상용 라이선스가 필요하다 (`docs/tool-findings.md`).
- 유사 서비스(Genspark, NotebookLM, Gamma)와 범용 AI 덱 생성기로 경쟁하는 것은 승산이 낮다고 판단했다 (2차 자료, 계획 문서 §8).

## 🎯 Decision
이 프로젝트는 **사용자 본인이 영상·자료를 만들어 쓰는 개인 제작 도구**로 시작한다 (2026-10-31 사용자 결정). 다른 사람에게 서비스로 제공하지 않는다.

## 📊 Consequences
- **긍정**: Hypit 은 자기 조직 업무로 쓰는 범위에서 허용으로 읽혀 자산 생성 공급자 후보로 남는다 (ADR-004 의 "기본 꺼짐, 건당 승인" 조건은 그대로). 경쟁 서비스 대비 시장성 검증이 필요 없고, 멀티테넌트 인증·결제·호스팅 설계를 하지 않는다.
- **부정**: 다른 사람이 쓰게 만들 수 없다. UI 는 로컬 웹앱(ADR-004)에 머문다. 클라우드 렌더(`cloud`, `lambda`, `cloudrun`)는 여전히 사용자가 요청할 때만 쓴다.
- **중립**: 크레딧·라이선스 방침(작성자 설명란 표기, 브랜드 모방 블록 제외)은 본인 채널 업로드 기준으로 그대로 필요하다.

## 🔀 Alternatives
- **판매 제품**: 비채택 — Hypit 상용 라이선스 검토, 호스팅·결제, 경쟁 조사가 모두 필요하고 첫 제품의 검증 범위를 불필요하게 넓힌다.
- **미정 유지**: 비채택 — Hypit·클라우드 렌더 판단을 계속 미룰 수 없다.

## 📌 Status
Accepted (2026-10-31, 사용자 결정). 재검토 조건: 다른 사람이 이 도구에 자기 워크스페이스를 갖게 하거나 결과 도구 자체를 판매하려는 경우 (Hypit 멀티테넌트·재배포 조항에 해당할 수 있음).
