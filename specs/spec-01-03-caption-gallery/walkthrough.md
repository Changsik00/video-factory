## 💬 사용자 협의

- **주제**: 중단된 매트릭스 렌더 재개
  - **합의**: 남은 12개 스타일을 4개씩 나눠 재개 (PC 부하 때문에 70분 연속 실행은 중단했음)
- **주제**: `emoji-pop` 실패 원인
  - **사용자 질문**: PC 성능 문제인가
  - **처리**: 부하가 낮고 draft 화질에서도 페이지 로드 단계에서 막히므로 PC 성능 가능성은 낮음. 외부 폰트 가설은 curl 0.2초·다른 14개 정상이라 근거 약함. 1회만 더 시도 후 미해결 기록
- **주제**: 스킬 문제인가, 검증을 계속할 것인가
  - **합의**: 스킬이 아니라 컴포넌트 설계(어두운 배경 가정, 고정 위치) 문제. 갤러리 목적은 달성했으므로 정리 후 PR
- **사용자 판정**: 모음 영상 재생 판정은 **받지 못했다.** 사용자 지시로 판정 전에 정리·PR 진행

## 🔍 발견 사항

- 가독성 문제는 스킬이 아니라 컴포넌트 설계에서 나온다. `check` 가 모두 ok 여도 안 읽히는 조합이 있다 (spec-01-02 발견 재확인).
- scrim 은 자막이 아래쪽에 있는 스타일에서만 효과가 있다.
- `emoji-pop` 은 화질·부하와 무관하게 페이지 로드에서 막힌다. 원인 미확인.
- 러너 결함 수정: `check` 결과를 조합 범위로 한정, 자막 스크립트 오류 감지, 2초 배경 검은 화면 거짓 성공 방지.
- 스타일 라벨이 `data-chart` 제목과 겹친다 (미수정).
- 80개 연속 렌더는 약 1시간이고 PC 부하가 커서 4개씩 나눠야 안정적이다.
